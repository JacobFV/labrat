# Tappet — Test Plan

Tests are layered so that most regressions are caught without hardware. Requirement IDs are used in
CI output and in the QC checklist of [assembly.md](assembly.md).

## 1. Requirements under test

| ID | Requirement | Verified by |
|---|---|---|
| R1 | Tap accuracy p95 ≤ 2 mm, median ≤ 1 mm, over the whole default screen | T-HW-3 tap test |
| R2 | Either arm reaches the whole default screen at surface, approach and press heights | T-SW-2 workspace sweep |
| R3 | Firmware, Python and Kotlin kinematics agree to 1e-4 mm / 1e-4° | T-SW-1 shared vectors |
| R4 | All components agree with `config/robot.json` | T-SW-3 config consistency |
| R5 | Watchdog parks and relaxes arms ≤ 5 s + park time after the last command | T-FW-3, T-HW-5 |
| R6 | Head phone charges while connected via AOA | T-HW-2 |
| R7 | Brownout < 4.3 V pauses motion with `fault{brownout}` | T-FW-4, T-HW-6 |
| R8 | Stylus never bottoms out; contact guaranteed over ±1.9 mm z error | T-HW-4 |
| R9 | Agent tool calls map only to clamped (u,v) actions | T-APP-2 |

## 2. Software tests (CI, no hardware)

| Test | Where | What |
|---|---|---|
| T-SW-1 Kinematics vectors | `host/tests`, `firmware/test` (PlatformIO native), `android` unit tests | FK/IK on `config/kinematics_vectors.json` (generated by `host/tappet/kinematics.py`); unreachable and limit cases included |
| T-SW-2 Workspace | `host/tests` | 21×21 grid × 3 heights per arm: 1,323 poses, 0 failures (currently passing analytically, see [kinematics.md](kinematics.md)) |
| T-SW-3 Config consistency | `host/tests` | Firmware compiled defaults, Android assets and CAD parameters match `robot.json` |
| T-SW-4 Protocol | `host/tests` against `host/tappet/sim.py` | Every command in SPEC §4: ok path, `bad_args`, `unknown_cmd`, queue depth 16 → `queue_full`, `done` events in order, ≤ 512-byte lines |
| T-SW-5 Calibration math | `host/tests` | DLT homography recovers a known H from 9 noisy points (σ = 0.3 mm) with RMS < 0.5 mm; `uv_to_world`/`world_to_uv` round-trip |
| T-SW-6 Tap test pipeline | `host/tests` with simulator + synthetic touch log | Report fields, error statistics, SVG output |
| T-APP-1 Web API | Android instrumented / Python bridge | Pairing PIN → token; every `/api/*` rejects missing token (except `/api/pair`, touchpad events) |
| T-APP-2 Agent tools | Android unit | Tool schemas; out-of-range u,v clamped; motion tools disabled when link is down |

CI is in `.github/workflows/`. Firmware builds for `esp32-s3-devkitc-1` and runs native tests.

## 3. Firmware-in-the-loop (DevKit on the bench, no arms)

| Test | Procedure | Pass |
|---|---|---|
| T-FW-1 Boot | Power on, `hello` | `proto:1`, `servos:8` |
| T-FW-2 PWM | Logic analyser on PCA9685 ch0–7 after `joints` | Pulse width within ±5 µs (1 count) of `500 + s·2000/180` |
| T-FW-3 Watchdog | `enable`, send nothing | `watchdog` event at 5.0 ± 0.1 s, then park + OE high |
| T-FW-4 Brownout | Bench supply on servo rail, ramp to 4.2 V | `fault{brownout}`, queue paused; resumes on `enable` |
| T-FW-5 NVS | `calib_set save:true`, reboot, `calib_get`; corrupt NVS | Values persisted; corrupt → compiled defaults (F11) |
| T-FW-6 AOA | Connect each phone in the matrix below | Accessory mode in ≤ 3 s, app auto-launch, 10 min soak without dropped lines |

## 4. Hardware tests (full robot)

| Test | Procedure | Pass |
|---|---|---|
| T-HW-1 Power | Measure VIN, VSERVO idle and with all 8 servos sweeping | VIN 8.6–9.4 V; VSERVO ≥ 4.6 V under load |
| T-HW-2 Head charging | Head at 30% battery, app + camera running 30 min | Battery level rises; VBUS switch no FLT |
| T-HW-3 Tap test | `POST /api/taptest {n:100}`, per arm and `auto` | ≥ 99/100 registered, median ≤ 1.0 mm, p95 ≤ 2.0 mm, max ≤ 3.0 mm |
| T-HW-4 Z margin | Tap test with `surface_z` deliberately offset ±1.9 mm | 100% registered at +1.9; no stylus bottoming at −1.9 (spring travel witness mark) |
| T-HW-5 Disconnect | Unplug head mid-swipe | Arms park + relax ≤ 6 s; replug resumes |
| T-HW-6 Brownout | 5 V-only charger; then 15 W PD charger with fast moves | F4 refusal; F3 fault without reset |
| T-HW-7 Endurance | 10,000 taps over 8 h with re-check every 1,000 | p95 stays ≤ 2 mm with no recalibration; no servo failures |
| T-HW-8 Stability | Head (220 g) at full tilt down + arms extended to far corner | Robot doesn't tip; base doesn't slide on desk |
| T-HW-9 Thermal | 1 h continuous agent session, 25 °C room | Head stays below Android "severe" thermal status; servo case < 50 °C |
| T-HW-10 Keyboard | Type a 40-char string via `/api/type` on iOS keyboard | ≥ 39/40 correct characters |

## 5. Android head compatibility matrix

AOA support varies by vendor. Each candidate head phone gets T-FW-6 + T-HW-2 + T-HW-9.

| Phone | Android | AOA | Charges while accessory | Camera at tray pose | Status |
|---|---|---|---|---|---|
| Pixel 6a / 7a | 14–15 | | | | to test (reference) |
| Samsung Galaxy A-series (A14/A15/A54) | 13–14 | | | | to test |
| Motorola Moto G (2022+) | 12–14 | | | | to test |

Phones that fail AOA can still use the USB-serial (OTG) or Wi-Fi transports (failure mode F2 in
[architecture.md](architecture.md)), but they then run on battery or need a separate charger.

## 6. Target phone matrix

T-HW-3 on each target device profile: iPhone 15/16 (6.1", default), iPhone SE (4.7"), iPhone 15/16 Plus
(6.7", shims removed; verify reach), Pixel 8, Galaxy S23. Rerun with and without a thin case.

## 7. Release gates

* **Every commit:** T-SW-*, firmware build.
* **Every firmware release:** T-FW-* on one bench unit + T-HW-3/5 on one robot.
* **Every shipped unit (CM):** QC checklist in [assembly.md](assembly.md) (subset of T-HW-1/3/5).
* **Before launch:** full T-HW-* on 5 units from the production line, plus the compatibility matrices.
